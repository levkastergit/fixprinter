# 🖨 FixPrinter

Программа для Windows, которая сама находит и чинит типовые проблемы с печатью. Красивое окно, одна кнопка — «Найти проблемы и починить».

## Скачать

👉 Готовый exe — на странице [Releases](https://github.com/levkastergit/fixprinter/releases/latest). Скачайте `FixPrinter.exe` и запустите (программа попросит права администратора — они нужны, чтобы перезапускать службу печати).

## Что проверяет и чинит

| Проверка | Починка |
|---|---|
| Служба печати (Spooler) не работает или выключен автозапуск | Запускает службу, включает автозапуск |
| Застрявшие задания в очереди печати | Отменяет задания, чистит папку `spool\PRINTERS`, перезапускает службу |
| Принтер в «автономном режиме» (offline) | Переводит принтер обратно в онлайн |
| Сетевой принтер недоступен по сети (TCP-порт) | Сообщает причину и что проверить |
| Нет бумаги / замятие / открыта крышка / нет тонера | Показывает, что нужно сделать на самом принтере |
| Служба RPC, папка очереди, принтер по умолчанию | Проверяет и чинит, где возможно |

## Логи

Всё, что делает программа, пишется в лог: `%LOCALAPPDATA%\FixPrinter\logs\`.

Если с первой попытки починить не удалось, программа предлагает **отправить логи на GitHub**: открывается форма нового issue в этом репозитории с уже вложенным логом (нужен аккаунт GitHub, остаётся нажать «Create»). Разработчик смотрит лог и выпускает новую версию с исправлением конкретной проблемы.

## Сборка из исходников

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0):

```powershell
dotnet publish src/FixPrinter -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

Готовый файл: `src/FixPrinter/bin/Release/net8.0-windows/win-x64/publish/FixPrinter.exe`.

## Технологии

- C# / .NET 8, WPF (тёмная тема)
- WMI (`Win32_Printer`, `Win32_PrintJob`, `Win32_Service`, `Win32_TCPIPPrinterPort`)
- Один самодостаточный exe, установка не нужна
